Scriptum — отчет по релизам (done.txt)
=====================================

Что за проект:
Читает .md файл, достает оттуда Java-код и запускает его.
Пишешь текст + код в одном файле, запускаешь — работает только код.

Как запустить:
  java Main file.md
  где file.md — твой markdown с блоками ```java.

Формат блока:
  ```java class="run"
  ...твой код...
  ```

-------------------------------------
v 0.4 (новая, задача называлась "v 0.2") — только class="run"
-------------------------------------
Что сейчас:
- Открытие блока = строка начинается с ```java (после trim).
- На ЭТОЙ ЖЕ строке ищем class=. Значение может быть в " ", в ' ' или без кавычек.
- Два флага: inside (мы внутри блока) и take (этот блок с class="run").
- Закрытие = любая строка с ``` пока мы внутри.
- Копим в builder только если inside && take.
- Если builder пустой — пишем "Блок class="run" не найден" и выходим, run.java не трогаем.
- Дальше все как в v0.3: пишем src/run.java и запускаем.

Примеры:
  ```java class="run"   -> берем, запускаем
  ```java class="other" -> пропускаем
  ```java               -> пропускаем (class нет)
  ```python             -> пропускаем (не java)

Зачем два флага:
  inside говорит ГДЕ мы (внутри блока или снаружи).
  take говорит ЧЕЙ это блок (нужный или чужой).
  Без take пришлось бы копировать все подряд.

Проверка:
  Тест: файл с class="other" + class="run" + python.
  Итог: в run.java попал только RUN_OK, запустился, напечатал RUN_OK.
  Тест без run: печать "Блок class="run" не найден", выхода с ошибкой нет.
  javac: сборка чистая (BUILD_OK).

-------------------------------------
v 0.5 — каждый класс в свой файл
-------------------------------------
Почему твой файл не запускался:
- Прошлая версия брала только ```java class="run".
- А в file.md просто ```java без class — фильтр его выкидывал.
- Плюс старый запуск через "java src/run.java" требовал main(String[] args),
  а в file.md main() без аргументов — java его не видел.

Что сейчас:
- Берем ВСЕ ```java блоки, class="..." теперь не обязателен.
- Имя файла: сначала смотрим class="..." в строке забора,
  если нет — ищем "class Имя" внутри кода, если и там нет — Block1, Block2.
- Блоки с одинаковым именем склеиваем в один файл.
- Все файлы компилируем разом через javac (чтобы классы видели друг друга).
- Запускаем только те, где есть main( — хелперы без main не трогаем.
- Твой file.md работает как есть: имя run достали из кода, javac схавал
  main() без аргументов (ему так можно), запустили, напечатал 4.

Примеры:
  ```java                  -> имя из кода (class run -> run.java)
  ```java class="Helper"  -> Helper.java
  два блока class="run"   -> склеятся в один run.java

Проверка:
  file.md (старый формат) -> Сохранен src/run.java, Запущен класс run, вывод 4.
  multi.md (Helper + run) -> два файла, запущен только run,
    вывод HELLO_FROM_HELPER + RUN_DONE, без ошибки про Helper.
  javac: сборка чистая (BUILD_OK).
